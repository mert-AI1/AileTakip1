AİLETAKİP — GITHUB PAGES DEMO

Kurulum:
1. GitHub'da AileTakip deponu aç.
2. index.html dosyasını depo köküne yükle veya mevcut index.html dosyasının yerine koy.
3. Commit changes ile kaydet.
4. GitHub Pages ayarlarında yayın kaynağının doğru depo/branch olduğundan emin ol.

Notlar:
- Bu paket bir ön yüz prototipidir.
- Gerçek Gmail/şifre doğrulaması, aile kodu doğrulaması, canlı GPS ve sunucu bağlantısı henüz ekli değildir.
- Demo gizlice kamera açmaz veya ses kaydetmez.
- Gerçek konum özelliği için açık kullanıcı izni, kimlik doğrulama ve güvenli veri erişim kuralları gerekir.
- KVKK ekranı taslaktır; yayından önce projeye özel aydınlatma metni hazırlanmalıdır.
